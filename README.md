# Inticate Bot - Discord Bot Framework

> [!IMPORTANT]
> Since this project is mainly intended for internal use, the documentation is limited. If you are planning on using
> this for your own projects, make sure you have a good understanding of TypeScript and Discord.js.

A simple and ready-to-use Discord bot framework built with Discord.js and TypeScript. Inticate Bot is primarily used
for internal projects but is open for public use and contributions.
